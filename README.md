Sight at forty — a one-star review of an everyday essential.

`main.py` writes the 109-character entry to `/output/entry.txt`, offline and deterministically.
Run `python3 main.py` to write it; `python3 main.py --check` reads it back and reports a match.
MIT licensed. Entry text lives in `entry.txt`; the strongest candidates and scoring are in `research.md`.
